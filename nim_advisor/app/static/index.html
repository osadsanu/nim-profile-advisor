Internal GPU model ↔ gpu_device validation

NIM profiles target hardware with a PCI gpu_device id (e.g. 233b:10de), an internal gpu name (e.g. h200-nvl) or a compute_capability. Every value found in the manifests is checked against the NVIDIA driver README (supported GPU products) and the PCI ID repository, mapped to a GPU of the reference catalog and cross-checked: when a profile carries both a name and a device id, they must point to the same GPU. Re-run tools/validate_gpu_ids.py after refreshing the catalog.
