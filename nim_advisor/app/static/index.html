Step 1 · The problem

Your NIM picks its own profile. It doesn't always pick well.

First things first: what's a profile?

A NIM is an AI model, boxed up and ready to run. Inside the box sits a whole rack of profiles: the same model, pre-tuned for one exact GPU setup. Think shoe sizes. Same shoe, but only one pair really fits you.

Nerd note A profile is a prebuilt engine for one combination of GPU model, GPU count, precision (FP8, BF16, …), backend (TensorRT-LLM, vLLM, …) and goal (latency or throughput). Some NIMs ship dozens.

At startup, NIM picks one for you

When the container starts, NIM checks the ID of your GPU and grabs a profile by itself. The catch: many of the fast profiles are built for the H200 SXM, and PCAI G2 runs the H200 NVL. Same family, different ID. So NIM shrugs and hands you the one-size-fits-all pair.

Nerd note 2335 (H200 SXM) is not 233b (H200 NVL), so NIM ignores the optimized engine and falls back to a generic one. Some manifests are simply wrong, too: 45 profiles in 17 older LLM NIMs carry the L40 ID under the name L40S, so a PCAI G1 L40S node never gets them.

Step 3 · The payoff

Paste one line. Deploy. Done.

One setting. That's the whole trick.

In HPE MLIS, open your packaged model and go to the Advanced tab. Under Environment variables, add NIM_MODEL_PROFILE and paste the profile ID you copied as its value. Save and deploy. No YAML, no command line.

Nerd note Paste the full ID: the copy button gives you all of it, even when the advisor shows a shortened one. Leave the Arguments field as it is, the profile only needs the environment variable.

Internal GPU model ↔ gpu_device validation

NIM profiles target hardware with a PCI gpu_device id (e.g. 233b:10de), an internal gpu name (e.g. h200-nvl) or a compute_capability. Every value found in the manifests is checked against the NVIDIA driver README (supported GPU products) and the PCI ID repository, mapped to a GPU of the reference catalog and cross-checked: when a profile carries both a name and a device id, they must point to the same GPU. Re-run tools/validate_gpu_ids.py after refreshing the catalog.
